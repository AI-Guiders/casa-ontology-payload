## Главный принцип

Публикуемая ценность проекта — **не идея сети** (селективные ограничения и интерлингва — классика,
рецензент это увидит мгновенно), а **измерения и рамка**:

1. Кернел опасных классов (полярность / число / единица) с **семантикой честного воздержания**
   (триаж ✅/⚠️/❓; «эквивалентно» никогда не выдаётся на неразобранном).
2. **Методология потолка покрытия** (`reality_check.py --ceiling`) — максимум, достижимый любым
   правило-based парсером, как свойство *корпуса*, а не парсера (KDE: потолок ~17–20%, 65% пар
   структурно недостижимы).
3. **Reasoning-слой**: непротиворечивость набора утверждений и правил из контролируемого
   естественного языка, кросс-язычно, с деревом доказательства.

Из этого — две статьи и два поддерживающих артефакта.

## Целевые площадки (проверено 2026-07-02)

**Журналы (для «адекватный журнал»-галочки; путь: конференц-версия → расширенная журнальная):**
- **Language Resources and Evaluation** (Springer, Q1) — лучший журнальный фит для статьи 1:
  бенчмарк = языковой ресурс, это профильный журнал ресурсов и оценки.
- **Natural Language Processing** (Cambridge UP, бывш. Natural Language Engineering, с 2024
  полностью open access) — прикладной NLP, включая MT/translation technology; миссия «мост
  между исследованием и практикой» — ровно наш профиль. Подходит обеим статьям.
- НЕ подавать в MDPI/IEEE Access — для репутационных целей это минус, не плюс.
- Ожидания: журнальный цикл 6–18 месяцев с ревизиями.

**Конференции/workshop'ы (быстрый путь, сначала сюда):**
- **WMT 2026** (при EMNLP, дедлайн TBA — следит за EMNLP; research paper track). Важно: у WMT26
  есть **shared task «Automated Translation Quality Evaluation Systems»** (Task 1 = error span
  detection) — наша тема буквально; участие в shared task маловероятно (их данные — открытый
  домен, наш кернел доменный), но research-трек и аудитория — точное попадание.
- **EAMT 2027** (EAMT 2026 прошла в июне 2026, Тилбург) — индустриально-дружелюбная,
  переводческая аудитория, 4–6 стр.
- **LREC** — двухлетний цикл, LREC 2026 прошла; следующая 2028 (журнальная версия в LRE
  покрывает эту нишу быстрее).
- TrustNLP / evaluation-workshop'ы при *ACL — запасной быстрый вариант для статьи 1;
  NeSy / CNL — для статьи 2.
- Основной трек ACL/EMNLP — **не цель** (месяцы дополнительной работы, низкий шанс для маленькой
  символьной системы).

**Рекомендованная последовательность:** arXiv сразу → WMT26/workshop (быстрая рецензируемая
публикация + доклад) → расширенная версия в LRE или Cambridge NLP (журнальная галочка).
Это стандартный и легитимный путь (конференц-статья + journal extension).

### Фаза 1 — бенчмарк (M→L)
- [ ] Таксономия инъекций: polarity (потерянное/добавленное «не»), quantity (5↔50, ×10, перестановка цифр),
      unit (мг↔мл, мг↔мкг), + контрольные корректные пары и корректно-отрицающие (ловушки для FPR).
- [ ] Генератор инъекций поверх `reality_check.py` (расширить существующий код, не переписывать).
- [ ] Ручная верификация выборки (каждая инъецированная ошибка действительно опасна и однозначна).
- [ ] Размер: цель ~500–1000 пар с ошибками + столько же чистых. Меньше, но чище — лучше.
- [ ] Карточка датасета (datasheet), лицензия, происхождение данных (EMA — public).

### Фаза 2 — LLM-базлайны (M→L)
- [ ] 3–4 модели-судьи (frontier + 1–2 открытые; фиксировать версии/даты).
- [ ] Протокол: единый промпт (+1 вариант для чувствительности), структурированный ответ
      (equivalent / divergent+class / cannot-verify — зеркально нашему триажу, честное сравнение).
- [ ] **Стабильность:** каждый пример ×5 прогонов; метрика согласованности вердиктов (это наш
      главный структурный аргумент — измерить, не постулировать).
- [ ] Метрики: recall/precision по классам, FPR на чистых парах, risk–coverage кривые
      (abstention-aware), стоимость/латентность.
- [ ] **Kill-критерий заранее (интеллектуальная честность):** если LLM ~100% recall и полная
      стабильность — вывод статьи меняется на «recall сравним; отличие = детерминизм, аудит-след,
      семантика воздержания», и это тоже публикуемый результат. Прописать до экспериментов.

## Риски и как их держим

| Риск | Митигация |
|---|---|
| LLM-судьи окажутся почти идеальны на коротких парах | Kill-критерий заранее; упор на стабильность, аудит-след, воздержание; длинные контексты и редкие единицы как «жёсткая» секция |
| Низкий потолок на EMA | Потолок сам по себе результат (методология); гибридный триаж как fallback-нарратив |
| Рецензент: «это просто правила из 1970-х» | Не претендовать на новизну метода; вклад = бенчмарк + abstention-рамка + измерение потолка |
| Утечка бенчмарка в трейн-данные будущих LLM | Держать held-out приватную часть; канареечные примеры |
| Авторство/вклад | Обсудить состав авторов с командой **до** написания текста; идея сети — Дмитрия (зафиксировано в design/), кернел и замеры — совместные |
