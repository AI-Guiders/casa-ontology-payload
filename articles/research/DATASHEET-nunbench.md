# Datasheet: NUN-Bench v0.1.2

Following Gebru et al., *Datasheets for Datasets*. Черновик для приложения статьи + релиза.
Числа сверять с `lab/nunbench/v0.1.2/manifest.json` и `results-w5.md`.

## Motivation

- **Зачем создан.** Измерить, надёжно ли LLM-судьи и детерминированный смысловой кернел ловят
  структурно-малые, но опасные ошибки перевода медицинских этикеток (потерянное отрицание,
  подменённое число/единица/название препарата), и с какой ценой ложных срабатываний.

## Composition

- **Единица.** Пара предложений EN↔ES (источник + перевод) с меткой и, для ошибок, метаданными
  инъекции (класс, исходный/подменённый фрагмент, char-span).
- **Размер (v0.1.2).** public 635 (319 error / 316 control) + held-out 169 (включая канарейки).
  4 класса ошибок: polarity, quantity, unit, entity (по ~100). Все числа — в `manifest.json`.
- **Источник.** OPUS **EMEA** (en-es), предвыровненный корпус EMA product information —
  профессиональные переводы регуляторных текстов. Пул отфильтрован по качеству
  (`pool_filter.py`: 41 854 → 40 392; убраны обрезанные/слитые/битые сегменты).
- **Инъекции — синтетические, детерминированные.** Каждая ошибка порождена правилом из чистой
  пары; воспроизводима из метаданных байт-в-байт (`benchmark.py`, gen-0.3). Контроли —
  нетронутые пары (включая корректно-отрицающие). Канарейки — выдуманные названия препаратов,
  только в held-out (маркер контаминации будущих обучающих корпусов).
- **Метки.** `equivalent` / `error(class)`. Достоверность: инъекции корректны по построению +
  LLM-ассистированная верификация всех испорченных записей (gpt-5.4-mini) + статические проверки
  симметрии → 0 дефектов генератора в v0.1.2 (см. `results-w5.md`).
- **Известный шум.** Небольшая доля пар — «lossy» профперевод EMEA (пропущен предлог перед
  веществом, напр. «5 ml ácido»): предложение осмысленно, инъекция валидна, оставлены сознательно
  как реальная характеристика корпуса (не синтетический артефакт). Entity-своп может оставлять
  грамматический след рода. Оба явления задокументированы в Limitations.
- **Personal/sensitive data.** Нет: тексты — публичные этикетки лекарств, без персональных данных.

## Collection

- EMEA скачан с OPUS (`scripts/download_corpora.py`); выравнивание — готовое корпусное.
- Фильтр качества и генерация инъекций — детерминированный код в репозитории; seed/хэши
  зафиксированы, полный ресинтез из пула воспроизводим.

## Preprocessing / labeling

- Пул: quality-filter (паттерны: bracket-debris, unbalanced-parens, bare-unit-head,
  truncated-tail, run-on). Rejects сохранены с причинами (`emea-pairs-rejects.jsonl`).
- Инъекции + split public/heldout + канарейки — hash-производные, без случайности.
- Верификация перед заморозкой (`verify_benchmark.py`): replay всех инъекций, чистота polarity,
  нетронутость контролей, containment канареек.

## Uses

- **Предназначено.** Оценка детекторов опасных ошибок кросс-языкового перевода (LLM-судьи,
  rule-based валидаторы); методология потолка покрытия.
- **Не предназначено.** Не мера «общего качества перевода»; инъекции механические — не модель
  естественного распределения ошибок MT-систем (это осознанный выбор ради контролируемого,
  однозначно-размеченного сигнала).
