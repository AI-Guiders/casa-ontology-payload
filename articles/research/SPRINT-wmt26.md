## ⚠️ Решение по языкам и источнику (обновлено 2026-07-02)

**Решение: добавляем испанский (EN↔ES — основная пара реальных данных), русский остаётся
третьим языком на курируемых формах.** Мотивация:
- EMA публикует на испанском (офиц. язык ЕС) → возвращается источник реальных этикеток.
  Более того, на OPUS есть готовый корпус **EMEA** (предвыровненные медицинские EN‖ES тексты) —
  снимает ручное выравнивание. Для en-ru EMEA не существует.
- KDE4 en-es на OPUS даёт прямое сравнение ceiling-числа с уже измеренным en-ru (~17–20%) —
  бонус-таблица для статьи (методология потолка на двух парах).
- RU не выбрасываем: три языка (включая контраст письменностей) делают тезис
  «граф язык-независим» сильнее; RU-трек — только курируемые формы, без реальных данных.

**Технический объём испанского (только парсер-слой; генерация для статьи 1 не нужна —
`check_equivalence` парсит обе стороны, не порождает):**
1. ES-имена концептов (names-рёбра) для скоупа бенчмарка — данные, LLM-assisted + выборочная
   проверка (S→M).
2. Служебные слова в `parse.py`: предлоги (en/sobre/de/…), отрицание (no), связка (es/está),
   сочинение (y), условие (si…entonces), слова-числа (dos/tres/…); единицы (ml/mg) совпадают (S→M).
3. Множественное число: испанские -s/-es уже покрыты `_en_singulars`; добавить формы
   прилагательных по роду/числу как names (S).
4. **Язык как параметр парсинга**: `script_of` различает только кириллицу/латиницу — EN и ES
   не разделить по письму. У пар в бенчмарке язык стороны известен → прокинуть `lang` в
   parse/resolve и фильтровать names по языку. Критично из-за омографов (ES «red» = сеть,
   EN «red» = цвет) (M).

Итого ES-слой: **M (2–4 дня)**, ложится в недели 1–2, съедает буфер — риск учтён ниже.

## Риски спринта

| Риск | Митигация |
|---|---|
| ES-слой парсера съест больше M | скоуп жёстко ограничен бенчмарком (этикеточные формы); инъекции механические — не требуют полного покрытия; в крайнем случае нарратив B (потолок+воздержание) работает и при низком ES-покрытии |
| Верификация испанских пар (никто в команде не носитель) | EMEA — профессиональные переводы (выравнивание готово); инъекции механические (корректны по построению); LLM-assisted проверка + точечный native-спикер на выборке |
| Омографы EN/ES ломают парсинг | `lang`-параметр стороны (язык пары известен) — заложено в ES-слой |
| LLM-прогоны дороже/дольше ожидаемого | датасет 300–500 пар выбран под это; 5 прогонов только на подмножестве стабильности, если упрёмся |
| Двойное слепое рецензирование и наш публичный репозиторий | анонимный снапшот кода; публикацию бенчмарка на HF отложить до notification |
| Отпуска/занятость в июле | gates еженедельные — сорванный gate = ранний переход на fallback, а не аврал |
