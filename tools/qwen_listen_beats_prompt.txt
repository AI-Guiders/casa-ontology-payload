Ты размечаешь детский мультик для sensory imprint (слушание + просмотр, без субтитров-оракула).

## Два типа битов

### 1. paired — одна фраза, один кадр
Титры, рефрены, статичные иллюстрации.
```json
{"id": "b000", "kind": "paired", "t0": 0.0, "t1": 2.0, "frame_t": 1.0, "note": "заголовок"}
```
- t0/t1 — окно аудио (сек от начала видео)
- frame_t — момент репрезентативного кадра (когда текст/картинка «готовы»)

### 2. motion — одна фраза, несколько keyframes
Жесты: комод открывается, ящик, стиралка, Ванечка открывает.
```json
{
  "id": "b004",
  "kind": "motion",
  "t0": 7.0,
  "t1": 15.5,
  "note": "В большом комоде, в верхнем ящике, жили Колготки",
  "keyframes": [
    {"frame_t": 7.5, "note": "комод закрыт"},
    {"frame_t": 9.5, "note": "ящик приоткрывается"},
    {"frame_t": 11.0, "note": "ящик открыт, видны колготки"},
    {"frame_t": 14.0, "note": "полный кадр с текстом"}
  ]
}
```
- Один звук на весь бит (t0–t1)
- 2–6 keyframes на фазы движения (не 60 FPS — дискретные позы, как в анимации)
- frame_t каждого keyframe внутри [t0, t1]

## Правила
- Таймлайн без дыр: t1 бита N = t0 бита N+1
- paired: обычно 2–8 с
- motion: до ~15 с, keyframes по смыслу жеста
- Титры Lalabook накапливаются: кадр = весь экран в frame_t, звук = только новая строка
- «Страшно!» — отдельный paired бит
