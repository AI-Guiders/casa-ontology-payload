# lesson-21-spatial-between

«Между» на **одной оси** — два кадра, один meta id.

| frame | vis | meta |
|-------|-----|------|
| `geom-points-b-between-ac` | A — B — C, B посередине | «между» → `lang.meta.spatial.between` |
| `numberline-2-between-1-3` | 1 — 2 — 3, 2 посередине | тот же id |

Не смешивать с compare длины и с левее/правее в одном sleep.
