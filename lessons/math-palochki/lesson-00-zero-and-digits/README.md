# Lesson 00 — Ноль и цифры ↔ палочки

**Class:** math-palochki

## Goal

Before heaps and operations: **empty = 0**, count sticks `|` … `||||`, link **digit glyphs** `0`–`4` to the same numbers, RU phrases («ноль палочек», «одна палочка»).

## Agent cues

| Cue | Maps to |
|-----|---------|
| `0`, `ноль`, `пусто`, `ноль палочек` | `math.num.zero` |
| `1` … `4`, `1 = \|`, … | digit ↔ stick run |
| `одна палочка` … `четыре палочки` | phrase ↔ `\|`, `\|\|`, … |

## Note

Lesson 01 repeats stick counting for reinforcement; lesson 00 is the **zero + digit bridge** pass.
