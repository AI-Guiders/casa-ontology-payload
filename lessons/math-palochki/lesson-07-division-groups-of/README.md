# Lesson 07 — Деление: по N в кучке

**Class:** math-palochki  
**Prerequisites:** lessons 01–02 (heaps), 06 (multiplication as groups)

## Goal

`4 ÷ 2 = 2` means: split sticks into **groups of 2** → **2 groups**. Quotient = number of groups.

## Materials

Sticks or `|` on paper.

## Flow

1. Show `||||`, say: «четыре палочки».
2. Group: `(||)(||)` — «по две в кучке».
3. Ask: «сколько кучек?» → **2**.
4. Write: `4 ÷ 2 = 2`.
5. Point at parts: **делимое** (4), **делитель** (2 = size of group), **частное** (2 = how many groups).

## Check

- Draw `6 ÷ 3` with sticks; name all three roles.
- Wrong-direction trap: «6 ÷ 2» vs «6 на 2 кучки» — defer full contrast to lesson 08.

## Vocabulary

| Role | Term |
|------|------|
| all sticks | делимое |
| size of each group | делитель |
| number of groups | частное |
