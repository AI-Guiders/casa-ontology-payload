# Lesson 18: дроби на кучках

**Идея:** дробь — это **сколько кучек взяли из скольки равных**.

| Дробь | Запись | Смысл |
|-------|--------|--------|
| 1/2 | `(||) \|\|` | 1 кучка из 2 |
| 2/3 | `(||) [(||)(||)]` | 2 кучки из 3 |
| 3/4 | `()[()()()]` | 3 из 4 — ленивая запись |
| 3/4 | `(||) [(||)(||)(||)]` | то же: снаружи 1/4, в `[…]` три взятые |

- **Числитель** — сколько кучек **взяли**.
- **Знаменатель** — на сколько **равных** кучек разделили.

### Про `()` в 3/4

В `()[()()()]` скобки **не означают «ноль палочек»** из lesson 11 — просто **не стали рисовать палочки внутри** каждой кучки-доли. Одна пара `()` = одна кучка (одна доля), как `(||)` в первых примерах, только без штрихов.

Квадратные `[…]` группируют несколько кучек одной порцией.

Связь с lesson 08: `|||| на 2 кучки` — деление; здесь смотрим на **долю**, а не на частное.
