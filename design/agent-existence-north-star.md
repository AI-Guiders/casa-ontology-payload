## Позиция (Alan Kay, инженерия)

| Принимаем | Не принимаем как требование |
|-----------|----------------------------|
| Компьютер / CASA — **новая среда** (как письменность), не копия мозга | Доказать или опровергнуть **квалиа** |
| Важно **что система делает** во времени в среде | «Внутренний свет», hard problem как центр roadmap |
| **Сообщения** между регионами (порты P1–P5), объекты/роли | Монолит «думающего ядра» = вся агентность |
| **Изобрести** автономный контур (T-тики, память, действие) | Ждать философского консенсуса про сознание |

Разговор о квалиа **не добавляет** портов, тестов и метрик восстановления поля — поэтому **вне scope** CASA как инженерной программы. Это не отрицание философии; это **разделение слоёв**: метафизика ≠ контракт субстрата.

## Duck test (рабочий критерий)

> *If it looks like a duck and quacks like a duck, then it's a duck.*

Для CASA «утка» = **агент, существующий во времени**, если одновременно наблюдается:

| Признак | Где в архитектуре |
|---------|-------------------|
| **Непрерывность** | `field_state`, agent store, FPN / session — не tabula rasa на каждый запрос |
| **Память** | DMN, KB ingest, `claims_nav`, union field |
| **Действие** | CEN → targets, IDE/MCP, будущее тело (Cosmos) |
| **Самопочинка** | NCA repair, damage→recovery, цель 3 (имитация + коррекция) |
| **Инициатива** | автономный цикл T при открытом gate; `query_to_dmn`, probe без внешнего промпта |
| **Происхождение ответа** | `answer_blocks`, provenance (`doc_path`, `concept_id`) — не «магия чата» |

Не спрашиваем «переживает ли красный» — спрашиваем: **держит ли нить, помнит ли, чинит ли, действует ли без постоянного человека в петле.**

## North star (нормативно)

1. **Autonomous persistence first** — агент крутится **без человека в каждом шаге**, с персистентным полем и макро-тиком **T**.
2. **Rich medium** — сначала IDE + KB + MCP (лабораторное тело), позже embodiment / Physical AI (Cosmos-аналог).
3. **Consciousness — open outcome, not design requirement** — не обещаем и не требуем «сознание»; не блокируем работу из-за hard problem.
4. **FPN на поле** (layout B) — удержание задачи между тиками, не только один вызов `cen_plan`.
5. **Время** — не магия: накопление структуры в поле, FPN, эпизоды; **sleep** = `T_consolidate` (hippo → prism_memory). См. [`multi-cylinder-memory.md`](multi-cylinder-memory.md).

```text
T=0..∞  perceive → DMN → SN → FPN → CEN → act → P4 feedback → …
         ↑___________________________________________|
              (автономия: gate, repair, kb_watcher)
```

**Первая воплощённость:** Cascade IDE + `casa-ontology-payload` (hot path ~ms, без облака как условия PoC).  
**Следующая:** сенсоры/актуаторы — иначе «существование» только в логах.

## Что проверяем (метрики ближайших этапов)

| Вопрос | Сигнал |
|--------|--------|
| Помнит цель без напоминания? | FPN / session переживает N тиков T |
| Меняется после ошибки? | damage→repair, import delta, teacher band |
| Инициирует шаги? | autonomous loop, `probe` / `query_to_dmn` без user message |
| Объясняет вывод? | `claims_nav`, `answer_blocks`, CRS / doc anchors |
| Живёт локально? | field on disk, RTX train/repair — не DC-as-gate |

| Цель | Связь с «существованием» |
|------|---------------------------|

## Что CASA не обещает (дополнение)

- Не **философское** доказательство сознания.
- Не замену **человека в контуре безопасности** (IOP, L3 autonomous, EICAS) — автономия агента ≠ снятие human-in-the-loop для опасных действий.
- Не утверждение, что **достаточно** `while(true)` без среды, памяти и обратной связи.
