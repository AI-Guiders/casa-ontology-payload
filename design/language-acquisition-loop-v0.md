# Language acquisition loop — «как ребёнок», не «объясни мне падеж»

**Status:** north star (переформулировка после realize v0)  
**Date:** 2026-05-28  
**Предшествует этому:** [`bukvar-text-modality-v0.md`](bukvar-text-modality-v0.md) — буква → слог → слово, массовый listen в цилиндр  
**Companion:** [`infancy-corpus-phases-v0.md`](infancy-corpus-phases-v0.md) — фазы 0–5, корпуса, белый шум vs сказка  
**Supersedes framing in:** [`articulation-explain-concept-v0.md`](articulation-explain-concept-v0.md) (карточки «для ответа пользователю» — не цель)

## Ошибка предыдущего шага

Путаница двух задач:

| Задача | Кто учится | Пример |
|--------|------------|--------|
| **Педагогика наружу** | пользователь читает ответ агента | «Дательный — это…» |
| **Понимание внутри** | **сам агент** стабильно ведёт себя как знающий | слышит «маме», сам говорит «маме», не «мама» в той же роли |

Realize v0 и concept cards лечат **первую**; пользователю нужна **вторая**.

**Понимание падежа** здесь = не абзац в KB, а **устойчивая структура на поле** (связи `мама`↔`маме`↔`кому`↔`согласно+приказу`) + **способность породить форму в контексте**, а не процитировать правило.

## Метафора (канон)

> **Термины:** инженерно — **`surface`** (вывод с поля), не «лепет» / `babble`. См. [`casa-glossary-v0.md`](casa-glossary-v0.md) § *Продукция с поля*.

```text
1. Слушает речь        — поток входа (listen / ingest)
2. Выводит surface     — черновик строки с поля (ошибки допустимы)  [было: «лепет»]
3. Мягко корректируют  — critic / teacher → hippo → sleep
```

Это не очередной слой шаблонов. Это **контур обучения во времени** (CASA цель **3**: имитация + ошибка), см. [`agent-existence-north-star-v0.md`](agent-existence-north-star-v0.md).

## Что есть сейчас (честно)

| Есть | Это про понимание? |
|------|-------------------|
| KB + `claims_nav` | **Диск** / канон — как речь взрослых вокруг, не «мысль агента» |
| `field_state` + NCA repair | **Тело** — что переживает damage; учится восстанавливать **раскладку** токенов |
| CEN + realize | **surface / articulate v0** — строка из слотов; не доказательство, что агент *понял* дательный |
| Bench read@1 / paste | **Подражание + подбор** по словам, не внутренняя грамматика |

«Выпуск из яслей» по write@sketch ≠ «агент понимает падежи».

## Смысл, не RAG (общий принцип KB и поля)

При проектировании **KB** мы сознательно **не** клали «тонну справочного текста» под retrieval: из markdown **извлекали** claims, `concept_id`, graph — **смыслы**, связи, правила. Hot path: status → playbook → matrix → kb **по запросу**, не «загрузи всё».

**CASA с нуля — та же идея**, другой носитель и другой учитель:

| KB (канон) | Поле + цикл обучения |
|------------|----------------------|
| ingest doc → extract claim | listen / babble → **сдвиг на решётке** |
| `concept_id` + `E:` | `M:`, `C:`, `W:*`, hub между F и L |
| редактор / автор KB | explain → correct → направить |
| не цитировать простыню | **само вывести** правило, закономерность, значение |
| git = диск, не «я» | `field_version↑`, hippo → sleep → memory |

Агент **не заучивает абзацы**. Среда (KB, учитель, корпус) даёт **материал и коррекцию**; субстрат **сжимает** пережитое в структуру — связи на полях, episodic в hippo, схемы в F0, слова в L2 — и **использует** её на следующих тиках (digest, babble, compose, repair).

```text
  среда (текст, пример, картинка позже)
       →  explain / correct / направить
       →  extract на поле (не dump в prompt)
       →  remember: ltm + hippo + hub
       →  use: SN → CEN → act / articulate
```

**RAG-обман** (и для KB, и для поля): ответ = нашли похожий chunk. **Цель:** ответ = **активировалась структура**, которую агент **сам** накопил через цикл; provenance (`concept_id`, `doc_path`) — для аудита, не для подмены памяти.

См. [`CASA-ADR-0002-agent-memory-ltm-nca.md`](CASA-ADR-0002-agent-memory-ltm-nca.md), [`f0-math-logical-layer-v0.md`](f0-math-logical-layer-v0.md) (смысл операции vs слово «две»).

## Целевой контур (инженерно)

```text
     ┌─────────────── LISTEN ───────────────┐
     │  текст/диалог, TTS, KB ingest,       │
     │  повторяющиеся пары в контексте      │
     │  (мама / маме / согласно приказу)    │
     └─────────────────┬────────────────────┘
                       ▼
              field encode + NCA
              (связи крепнут, не цитаты)
                       │
     ┌─────────────────▼────────────────────┐
     │  BABBLE — агент что-то говорит/пишет │
     │  (articulation = ранний выход поля)  │
     └─────────────────┬────────────────────┘
                       ▼
     ┌──────────── CORRECT ─────────────────┐
     │  teacher: «не приказа, а приказу»    │
     │  → loss / repair / negative pair     │
     │  → не новый claim «для ответа»,     │
     │     а сдвиг поля и habit            │
     └─────────────────┬────────────────────┘
                       │
                       └──► снова LISTEN …
```

| Фаза | Среда (lab v0→v1) | Сигнал успеха |
|------|-------------------|---------------|
| **Listen** | корпус коротких реплик, dialogue + rules **как речь**, не exam-QA | после encode соседние concept_id **сходятся** на поле (metric TBD) |
| **Babble** | `answer_text` / будущий emit без штрафа за первую ошибку | агент **пытается** говорить, не молчит |
| **Correct** | human/teacher band, paraphrase «вот так», compile-style loop для языка | **та же** ситуация → форма **ближе к норме** после 1–3 коррекций; repair mix растёт **на held-out фразах**, не на тех же queries |

**KB** в этой модели — **запись среды и коррекций** (что говорили, что поправили), не готовая энциклопедия, которую агент заучивает для цитирования.

## Память только в «цилиндре»

**Структура** этой памяти — букварная лестница B0→B3 ([`bukvar-text-modality-v0.md`](bukvar-text-modality-v0.md)): не мешок claims, а слои grapheme → syllable → word. Без неё «свой опыт» некуда записывать.

См. [`casa-cosmos-mapping-v0.md`](casa-cosmos-mapping-v0.md) §2 — **один буфер** `(x, y, z)`: DMN/SN/CEN на одной карте, фазы поршня `encode → repair → digest → gate`. Это и есть **цилиндр** — не метафора «ещё одной БД».

| Слой | Роль | Собственный опыт агента? |
|------|------|---------------------------|
| **Цилиндр** (`field_state` grid, NCA dynamics, digest после decode) | **Единственная живая память** — что пережито, повреждено, восстановлено, сдвинуто коррекцией | **Да** — только то, что **записано в grid** и меняет rollout |
| **Канон** (git KB, bundles, agent-notes) | Речь среды, учебники, импорт дельт — как радио/книги **вокруг** | **Нет** — общий диск, не «я помню» |
| **`claims_nav` + `claim.text` на hot path** (как сейчас в CEN) | Удобный индекс для IDE; по сути **внешняя RAM** | **Обман** — агент «знает», потому что прочитал JSON, не потому что у него внутри сложилось |

> **Собственный опыт** начинается, когда после listen / babble / correct меняется **снимок цилиндра** (`field_version↑`), а ответ идёт из **digest + динамики поля**, а не из `SELECT text FROM claims`.

```text
  ВНЕ цилиндра (канон)              ВНУТРИ цилиндра (опыт)
  ─────────────────────             ───────────────────────
  bundle.json, git KB    ──listen──►  encode → grid tokens
  teacher голосом/text   ─correct──►  repair / write tile
  (не копировать в ответ)            babble ← decode(digest)
                                     episod: T:, E: рёбра (roadmap)
```

### Что ломает модель сегодня

- CEN подбирает `answer_blocks` из **bundle claims** по словам запроса — это **библиотечный поиск**, не вспоминание.
- Union KB **перекодируется** в поле, но **продукция** всё ещё опирается на текст claim с диска.
- Коррекция почти не оставляет **эпизодического следа** в grid (только общий finetune NCA на каноне).

### Целевое правило (v1)

1. **Вход:** речь/текст → **только** `encode` в DMN (цилиндр).
2. **Мышление:** `repair` + `digest` — что активно **сейчас**, без чтения `claim.text`.
3. **Лепет:** articulation из **digest + слотов поля**; `concept_id` / `doc_path` — **provenance для человека**, не генератор фразы.
4. **Опыт:** пара «сказал X → поправили Y» → **delta write** на поле (отдельный слой эпизодов или усиление рёбер), `field_version++`; канон в git **опционально** зеркалить для аудита, не для hot path.
5. **Bench «понял»:** held-out фраза → форма из **decode после коррекции**, при **закрытом** `claims_nav` (ablation).

`model.pt` — **физика** цилиндра (как законы восстановления), не энциклопедия. Энциклопедия в каноне; **биография** — в grid.

## Связь с Exp J / L

- **J0 read** ≈ «слышит разные формулировки одного намерения» — ещё listen.
- **J write / realize** ≈ **lepет** — уже полезно, но не путать с пониманием.
- **Букварь текста (B0–B2)** — **до** этого контура: буквы/слоги в цилиндре, лепет по звукам ([`bukvar-text-modality-v0.md`](bukvar-text-modality-v0.md)).
- **Exp L4** (картинка+слово) — **после** слово уже в цилиндре: `vis.animal.cow` ↔ `lang.word.cow`.

Дательный **внутри** = когда «маме» в dialogue и «согласно приказу» в grammar **один кластер на поле**, и babble в новом предложении **вытягивает -е/-у**, не когда добавили карточку `explain_concept`.

## Что **не** делать как замену

- Не раздувать `explain_concept` для красивых лекций пользователю.
- Не мерить «понял» по paste_ratio или устному экзамену на **тех же** фразах из KB.
- Не ждать LLM на hot path как «внезапное понимание».

## Ближайшие шаги (когда пойдём в реализацию)

**Контракт понимания (Extract → Remember → Use, bench, hot path):** [`understanding-contract-v0.md`](understanding-contract-v0.md).

1. **Corpus listen** — речь в **цилиндр** (encode), не «ещё 200 claims для grep».
2. **Episodic write** — после correct: `field_write` / episodic channel (`T:`, `E:`), не только запись в markdown-KB.
3. **Babble from digest** — режим CEN **без** `claim.text` (ablation bench).
4. **Correct train** — windowed NCA на **том tile**, где лежит исправленная пара; `field_version` растёт.
5. **Held-out babble bench** — `claims_nav` off; pass = форма из decode после сессии коррекций.

## Для агента (Cursor)

При запросе «объясни падеж» от пользователя — можно **кратко** ответить человеку.  
При цели «агент **сам** понимает» — проектировать **listen → babble → correct**, не encyclopedia cards.
