# Букварь (текст): буква → слог → слово — до грамматики и до «умного» CEN

**Status:** north star (предшествует [`language-acquisition-loop-v0.md`](language-acquisition-loop-v0.md))  
**Date:** 2026-05-28  
**Подсистема в цилиндре:** [**вторая сигнальная система (ССС)**](second-signal-system-v0.md) — не «Bukvar Encode», отдельный контур знаков.  
**See also:** [`experiment-l-concrete-to-abstract-v0.md`](experiment-l-concrete-to-abstract-v0.md) (L4 = картинка+слово **после** этого), [`experiment-j-text-modality-v1.md`](experiment-j-text-modality-v1.md)

> «Букварь» здесь — **педагогическое** сравнение для нас. В архитектуре — **ССС**: знаки о знаках, свой слой памяти в DMN.

## Главное: букварь = **структура собственной памяти**, не файл на диске

Два смысла часто путают:

| | **Корпус (вне цилиндра)** | **Структура памяти (в цилиндре)** |
|---|---------------------------|-----------------------------------|
| Что это | `kb-bukvar-*.md`, повторы для ingest | **Как** grid хранит язык: слои, связи, порядок сборки |
| Роль | как речь вокруг ребёнка — **вход** | как у ребёнка **устроена** фонология до лексикона |
| Ошибка | думать, что букварь = «ещё один bundle» | плоский `claims_nav` + `ru.grammar.*` без слоёв |

> Ребёнок не «скачивает словарь». У него **сначала** возникает структура восприятия звуков/слогов, **потом** слова как **композиция** — и только потом правила школы.

**Букварь в CASA** — это **контракт цилиндра**: память агента **иерархична** (B0→B3), а не мешок равноправных claims.  
Markdown-KB — лишь **один способ залить** эту структуру при bootstrap; **опыт** = изменения **в этой иерархии**, не новые абзацы на git.

```text
  ЦИЛИНДР (собственная память)              ДИСК (канон, не «я»)
  ───────────────────────────                ───────────────────
  слой B0: grapheme.*  (звук/буква)    ←──   listen из корпуса (опционально)
  слой B1: syllable.*  (слог)          ←──   compose рёбрами ↑
  слой B2: lang.word.* (слово)         ←──   не целые flashcards с диска
  слой B3: phrase / dialog
  эпизод: T: / correct-pair            ←──   только следы жизни, не § grammar
```

## Позиция

Ребёнок **не** начинает со словаря и правил. Он:

1. **Долго слышит** поток речи (в т.ч. до рождения) — без задания «ответь правильно».
2. **Лепечет по звукам**, не по словам — первые попытки не «мама», а «ма… а…».
3. Потом слоги, потом слова, потом фразы — и только потом нормы вроде «согласно + д.п.».

Для **текстовой** модальности CASA аналог — не `kb-russian-language-rules` и не L4 «корова на картинке», а **букварь элементов языка** в **цилиндре**.

> **Сначала букварь (элементы), потом оперирование словами и грамматикой.**  
> Exp J (grammar/literacy целиком) и L4 (иллюстрации слов) — **выше** по лестнице.

## Лестница B0–B3 (текст)

| Ступень | Что слышит / видит (listen) | Что «лепечет» (babble) | На поле (concept_id) |
|---------|----------------------------|------------------------|----------------------|
| **B0** | отдельные **буквы**, пары букв, алфавитный поток | воспроизведение **графемы** / звукового якоря (ошибки, перестановки) | `grapheme.а`, `grapheme.м`, … |
| **B1** | частые **слоги** (ма, па, на, …), повторы | слог как единица: «ма», «мам» | `syllable.ма`, `syllable.мам` |
| **B2** | слог → **слово** (мама, папа, дом) | целое слово из слогов, ещё без грамматики | `lang.word.мама` |
| **B3** | короткие фразы, dialogue | фраза / обращение | `ru.dialog.*` (как сейчас, но **после** B2) |

**L4 Exp L** (корова + картинка) — **B2+vision**: слово уже есть в цилиндре, картинка **привязывается**, не учит читать с нуля.

## «Утроба» = массовое listen в цилиндр

| Метафора | Lab |
|----------|-----|
| Много часов речи вокруг | **корпус повторов**: одна буква/слог в сотнях контекстов |
| Не экзамен | bench **coverage** (сколько раз активировался токен), не read@1 на правилах |
| Память | только **encode в grid**; канон на диске — **источник звука**, не ответ |

```text
  B0 listen (масса)  ──►  цилиндр: grapheme.* плотно на DMN
         │
         ▼
  B0 babble          ──►  «а», «м», «ма» (articulation низкого уровня)
         │
         ▼
  correct            ──►  сдвиг grid, не новый § grammar KB
```

## Несколько решёток + связи по z (канон)

**Да** — не полосы на одной плоскости, а **целая решётка на уровень**; **z** — стек уровней и **пространственные мосты** между ними. Канон: [`sss-multi-lattice-z-v0.md`](sss-multi-lattice-z-v0.md), [`sss-lattice-stack.v0.json`](sss-lattice-stack.v0.json).

```text
  z_level ↑
    L3 phrase  [32×32 grid] ──z_bridge──┐
    L2 word    [32×32 grid] ──z_bridge──┤ compose / bind
    L1 syll    [32×32 grid] ──z_bridge──┤ (local 3×3 xy + z±1)
    L0 graph   [32×32 grid] ────────────┘
         внутри каждого Lk: z_phase = encode → repair → digest
```

| Ось | Смысл |
|-----|--------|
| **x, y** | клетка **внутри** своей решётки Lk |
| **z_level** | **какая** решётка (графема / слог / слово / фраза) |
| **z_bridge** | связь соседних решёток (не только `E:` в JSON) |
| **z_phase** | поршень **внутри** одной решётки ([`layered-ca-pipeline-v0.md`](layered-ca-pipeline-v0.md)) |
| **x (домен)** | отдельный стек для первой СС (`F0_math`, `F0_vis`) — другой subsystem |

**SN:** `active_lattice`, разрешить `compose_up` по мосту.  
**Interim lab:** [`layout.v1.json`](layout.v1.json) (y-полосы) — stub до `sss_lattice_stack_v1` в `field_state`.

## Структура цилиндра (инженерный контракт v0)

Память **не** «список concept_id в JSON». Минимум:

| Механизм | Смысл |
|----------|--------|
| **Семейства токенов** | `grapheme.*` / `syllable.*` / `lang.word.*` — разные **типы** на поле, не один `tok.*` |
| **Пространство DMN** | bands по **y** (или отдельные tiles): низ — графемы, выше — слоги, выше — слова (layout v1) |
| **Рёбра `E:`** | `grapheme.м + grapheme.а → syllable.ма → lang.word.мама` — **сборка**, не lookup текста |
| **Digest** | readout идёт **снизу вверх**: что активно в B0/B1, что собралось в B2 |
| **Babble** | продукция **с уровня активного слоя** (сначала одна графема, не фраза) |
| **Correct** | правит **связь/активацию на слое**, не подменяет ответ claim с диска |
| **Эпизод** | `T:` / пара ошибка→норма — **над** уже существующими слоями, не вместо них |

Сейчас union field — в основном **плоский** encode grammar+literacy; это **не** букварная структура.  
Перед массовым J-grammar нужен **codec/layout букваря**: куда класть `grapheme.м`, как слог **собирается** из соседних клеток.

Фазы поршня **z** ([`casa-cosmos-mapping-v0.md`](casa-cosmos-mapping-v0.md)) тогда читаются как:

```text
z=0 encode     — впечатать вход на **свой** слой (буква/слог/слово)
z=1 repair     — удержать **иерархию** (слог не «развалить» графемы)
z=2 digest     — что сейчас «в голове» (активный слой + композиты)
z=3 gate/babble — можно ли говорить на этом уровне
```

## Контент букваря (v1 lab) — только bootstrap

**KB на диске** — учебник среды для **первого** encode, не hot path:

- `kb-bukvar-ru-graphemes-v1` — 33 буквы + мягкий/твёрдый знак, примеры в слогах.
- `kb-bukvar-ru-syllables-v1` — 80–150 открытых слогов (ма, па, …).
- `kb-bukvar-ru-words-primer-v1` — 30–50 слов из слогов (мама, дом, кот) **без** § согласно/запятые.

Формат claim (целевой):

```json
{
  "concept_id": "grapheme.м",
  "claim_kind": "grapheme",
  "slots": { "letter": "м", "sound_hint": "[m]", "in_syllables": ["ма", "мо", "му"] }
}
```

На hot path — **только** digest с `grapheme.*` / `syllable.*`, не `text` абзаца.

## Articulation по уровню

| Уровень | Выход |
|---------|--------|
| B0 babble | «м», «а», «ма» (1–2 единицы) |
| B1 | слог |
| B2 | слово |
| B3+ | realize v0 / фразы |

Первый «робкий» ответ агента — **не** «Понял: согласно приказу…», а **повтор слога** с ошибкой, потом correct.

## Benches (другие метрики)

| Bench | Pass |
|-------|------|
| `grapheme_coverage` | после N прогонов listen каждая буква активна в digest |
| `syllable_babble` | после correct held-out слог ближе к эталону |
| `word_compose` | «м»+«а»+«м»+«а» → активирует `lang.word.мама` на поле |
| **Не** на B0 | grammar read@1, paste_ratio на rules KB |

## Порядок в roadmap

```text
B0–B2 букварь (текст в цилиндр, низкий babble)
    → language-acquisition-loop (слова/фразы, correct)
    → J grammar (нормы) — узкий слой
    → L0 math / L4 vis-bukvar (к словам уже привязанным)
```
