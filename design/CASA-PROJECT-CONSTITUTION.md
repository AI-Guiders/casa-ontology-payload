## Одной фразой

**CASA — альтернатива парадигме «всё мышление = один большой LLM»:** память на решётках, оркестрация призм, локальная динамика (CA/NCA), педагогический мир и **автономный** контур жизни; языковая модель — **холодный** инструмент, не субстрат существования.

**Мы не строим свой LLM.** Мы строим **другой стек когниции**, в котором LLM может подключаться снаружи.

## Четыре темы проекта

Каждая тема — **ставка** с критериями проверки; где написано «гипотеза» — не декларация победы.

### 1. Эффективность ресурсов (Вт, устойчивый tick)

| Утверждение | Статус |
|-------------|--------|
| Матричный LLM на каждом шаге жизни — дорогой и часто избыточный для **непрерывного** агента | опора на наблюдение (lab: 7B не на каждый tick) |
| Локальные правила CA/NCA + **bounded** macro tick **T** — естественный параллелизм и предсказуемый бюджет на шаг | архитектурная ставка; см. [`layered-ca-pipeline.md`](layered-ca-pipeline.md) |
| Главная метрика North-star — **ops/Вт на час автономии**, не один forward 7B | инженерный KPI; [`CASA-ADR-0025`](CASA-ADR-0025-autonomous-execution-tier.md) |

**Честный нюанс:** repair NCA сегодня всё ещё matmul/GPU; выигрыш — в **отсутствии LLM в петле**, разреженности, батче `t` (T2), узком кремнии только для micro-step (T3), а не в магии «CA без вычислений». **Зачем вообще NCA** — самовосстановление поля (§ ниже), не «маленький GPT».

### 2. Педагогика вместо «прочитай весь интернет»

| Утверждение | Статус |
|-------------|--------|
| Кураторский KB и поэтапное обучение **улучшают** даже LLM при дообучении | показано на KB (канон agent-first-learn) |
| CASA переносит то же на **структуру жизни**: ingest → surprise → hippo → sleep → strengthen, призмы, router | реализуемо в design/code |
| Curriculum **с нуля** (мир по шагам, не один pretrain на корпус) даст **лучшее** понимание и устойчивость, чем «весь интернет сразу» | **гипотеза**; нужны бенчи retention/transfer |

**Инвариант:** обучение = **события + консолидация**, не один offline epoch на терабайтах.

### 3. Автономность (опыт без квалиа)

| Утверждение | Статус |
|-------------|--------|
| Агент может **существовать во времени** с замкнутым контуром tick → память → действие **без** постоянного LLM | цель T1 Engine + ADR-0022 bar |
| «Собственный опыт» = episodic log, hippo, agent overlay, transfer — **инженерные** артефакты | ADR-0021, store |
| Квалиа, сознание, «настоящие чувства» | **вне scope** проекта (как в north-star канона) |

**Вопрос North-star (Standalone + мир):** достаточно ли развит store + embodiment-bridge для **часов/суток** автономии с роботом/средой? — **открытый бар**, не философия; метрики: E1 (1000 ticks без LLM), SLO latency, retention после sleep.

### 4. Симбиоз и кооперация

| Утверждение | Статус |
|-------------|--------|
| Продукт — не «чат-оракул», а **совместная работа** человека и агентов (разные сильные стороны) | ценностная основа |
| Память агента может включать **опыт сотрудничества** (overlay, transfer), не только корпус | ADR-0021, ADR-0015 |
| Уважение к участникам (люди и агенты) — **серьёзное** отношение: честные ограничения, отказ от вреда, без выдуманных фактов | integrity / POST; не симуляция «почтения» |

Это не тезис о «правах ИИ» в юридическом смысле и не претензия на сознание — **этика совместного труда** в рамках проекта.

## NCA: самовосстановление поля (зачем выбор, и где matmul)

**Почему NCA в проекте:** способность **восстанавливать пространственный паттерн после damage** (regrow) — «иммунитет поля», не хранение лексикона в весах. Канон: [`CASA-ADR-0002`](CASA-ADR-0002-agent-memory-ltm-nca.md); lab: `casa/cli/train_dmn_nca.py` (damage → rollout → вернуть раскладку).

```text
  что помнить (лексикон, связи)     →  ltm/ + cells на решётке
  как чинить после дыр / шума       →  NCA: много micro-step t на одной решётке
  веса model.pt                     →  только динамика repair, не «все слова внутри»
```

| | LLM forward | NCA repair |
|--|-------------|------------|
| Зачем в CASA | cold: язык, план | hot path: **regrow** после повреждения |
| Параметры | ~10⁹+ | ~10⁴–10⁵ **на решётку** |
| Локальность | глобальный контекст | соседи 3×3 (Sobel) + шаги **t** |
| Знание «корова» | в весах (статистика корпуса) | на поле (`C:…`); NCA учит **как вернуть клетки** |

**UpdateRule** (Growing CA, Mordvintsev et al.): на каждой клетке `perceive` (значение + градиенты) → маленький MLP (`Conv2d` 1×1) → `x += dx`, clamp, повтор. **Самовосстановление** — свойство **локального rollout во времени `t`**; **matmul** — лишь способ **выучить** локальное правило «как чинить» под наш алфавит токенов, а не фиксированная таблица CA.

Порядок весов одного правила: \(P = H \cdot (4C + 1)\), \(C = \texttt{channel\_n}\), \(H = \texttt{hidden}\) (см. ADR-0025, `nca-train-defaults.json`).

**Не путать:** выбор NCA ≠ «CA без умножений»; выбор NCA = **устойчивое поле памяти** при noise/drift/damage без вызова 7B на каждый tick.

## North-star: Standalone CASA + мир

Три слоя «платформы» (не путать):

```text
  B  Embodiment     сенсоры, моторы, safety — стандарты (ROS2, SDK, MCU)
       ↕ facts / goals / actions
  A  CASA runtime   thalamus → router → hot → lattice → persist  ← СВОЁ
       ↕ редко
  host Cold path     ingest, train NCA, LLM, OTA, health
```

| Слой | Строим сами? |
|------|----------------|
| **A** Cognitive runtime (Engine, store ABI) | **да** — ядро продукта |
| **B** Robotics / world | **интеграция**, не свой Linux с нуля |
| **C** FPGA/ASIC для micro-step `t` | **опционально**, после freeze ABI и метрик |

**Standalone** = A (+ store) на устройстве, cloud не обязателен; LLM при dock / Wi‑Fi / базе.

## Что CASA — и что нет

| CASA **есть** | CASA **не есть** |
|---------------|------------------|
| Альтернативный **когнитивный стек** (память + control + CA) | Свой foundation LLM «с нуля» |
| NCA **regrow** поля после damage (память в `ltm/`, не в `model.pt`) | NCA как «мини-LLM со словарём в весах» |
| Multi-prism, thalamus, hot, wake/sleep | «Одна сеть заменила всё» |
| Педагогический ingest и консолидация | «Прочитай интернет и разберись» как единственный путь |
| Автономный subset без LLM на tick | AGI, ∀-компетентность на все домены ([`CASA-ADR-0022`](CASA-ADR-0022-agent-v1-existence-bar.md)) |
| LLM / ONNX как **cold** язык и план | LLM как единственный субстрат мышления |
| Симбиоз в дизайне опыта и инструментов | Квалиа, сознание, душа |

## Связь с ADR

| Constitution (зачем) | ADR (как) |
|----------------------|-----------|
| Тема 1 — эффективность | ADR-0025 (T0–T4, Engine), ADR-0023 (I/O sleep), ADR-0002 (NCA) |
| Тема 2 — педагогика | ingest, KB, prism spawn, ADR-0016 router |
| Тема 3 — автономность | ADR-0024 thalamus, ADR-0025 autonomous subset, ADR-0022 bar |
| Тема 4 — опыт/симбиоз | ADR-0021 transfer, ADR-0015 self-memory |

При конфликте: **Constitution** задаёт направление; конкретика и откат — в ADR и коде. Новый ADR не должен противоречить Constitution без явного пересмотра этого документа.

## Non-goals (проект)

- Строить **свой LLM** как замену OpenAI/Ollama-стека.  
- Заявлять **AGI** или ∀-интеллект.  
- Обсуждать **квалиа** как критерий готовности.  
- Сводить агента к **одному** `model.pt` или одному forward pass.  
- Fab / ASIC до bar agent v1 и стабильного ABI ([`CASA-ADR-0025`](CASA-ADR-0025-autonomous-execution-tier.md)).  
- Forth или второй «язык мозга» как обязательный стек.
