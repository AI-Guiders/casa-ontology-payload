## Проблема (замечание пользователя)

Realize v0 отвечает на **«согласно приказа или приказу?»** нормой, но не на:

- что такое **дательный падеж**;
- почему он **дательный** (этимология / смысл);
- почему слова **согласуются** именно так;
- как связаны **управление** (предлог → падеж) и **согласование** (прилагательное → форма существительного).

В KB уже есть **фрагменты** (§ согласование, «согласно + дательный»), но они размазаны по rule-claims без слоя **педагогики**.

## Разделение слоёв

| Вопрос пользователя | Слой | Пример ответа |
|---------------------|------|----------------|
| «Как правильно?» | **norm** (realize v0) | «Верно: согласно приказу.» |
| «Что это и почему?» | **concept** (этот doc) | 3–5 предложений: смысл, вопросы, связь с согласованием, пример |
| «Покажи на примере X» | **instance** + concept | «Мама → маме, потому что …» |

```text
query  →  CEN (concept_id)  →  ConceptCard (slots в KB)
                              →  explain_concept(plan)  →  answer_text
```

Hot path **без LLM**: текст собирается из **слотов карточки** + фиксированного порядка абзацев (как realize, но длиннее и с логикой «урока»).

## ConceptCard (claim в bundle)

`claim_kind: "concept"` (отдельно от `claim` / rule).

```json
{
  "concept_id": "ru.grammar.case.dative",
  "claim_kind": "concept",
  "slots": {
    "title": "дательный падеж",
    "questions": "кому? чему?",
    "meaning": "часто получатель или адресат: кому дать, кому звонить, кому писать",
    "name_why": "название от «дать»: падеж часто отвечает на «кому передали / для кого»",
    "form_hint": "окончания меняются: мама → маме, приказ → приказу, договор → договору",
    "government": "некоторые конструкции требуют дательный: согласно чему? → согласно приказу",
    "agreement_link": "прилагательное/числительное в том же падеже: новый приказ → новому приказу",
    "lab": ["письмо маме", "согласно договору", "по правилам — согласно указу"]
  },
  "provenance": "РГ-80 / rusgram.ru — краткая выжимка, не цитата учебника"
}
```

Отдельная карточка **`ru.grammar.agreement`** — чтобы отвечать на «почему вторая, а не второй» без повторения всего §1 claim.

## UtterancePlan (расширение)

```python
@dataclass
class ConceptExplainPlan:
    act: str = "explain_concept"   # не explain_rule
    concept_id: str
    facets: list[str]            # порядок: meaning, name_why, form, government, agreement_link, examples
    slots: dict[str, str]
```

**Маршрутизация query → concept:**

| Сигнал в запросе | concept_id |
|------------------|------------|
| дательн, дат. п., кому/чему (обучение) | `ru.grammar.case.dative` |
| согласован, род, число, падеж (обучение) | `ru.grammar.agreement` |
| управлен, предлог + падеж | `ru.grammar.government` |
| «согласно» + «почему» / «что такое» | dative + link к government |

CEN: при intent **объяснение** + слова «что такое», «почему», «объясни понятие» — поднимать `claim_kind=concept` выше rule-claims.

## realize: `explain_concept` (псевдокод)

```text
1. Одно предложение — что это (title + questions).
2. Зачем так называется (name_why) — если слот есть.
3. Как узнать форму (form_hint) + 1–2 examples.
4. Связь: government ИЛИ agreement_link — только релевантные слоту запроса.
5. Не вставлять сырой claim.text; paste_ratio как в realize v0.
```

Пример **целевого** ответа (не шаблон одной строки):

> Дательный падеж — падеж, на который обычно отвечают «кому?» и «чему?».  
> Название связано с глаголом «дать»: часто обозначает получателя (кому дать, кому написать).  
> Форма слова меняется: *мама* → *маме*, *приказ* → *приказу*.  
> Предлог «согласно» как раз требует дательный: *согласно чему?* — *приказу*.  
> Если рядом прилагательное, оно согласуется в том же падеже: *новому приказу*, не *нового приказа*.

## Bench (критерий «умеет объяснять»)

Запросы:

- «Что такое дательный падеж простыми словами?»
- «Почему говорят согласно приказу, а не приказа?»
- «Почему без второй половинки, а не второго?»
- «Чем согласование отличается от управления?»

Pass: в ответе есть **meaning + (name_why или form) + (agreement или government)**; `paste_ratio < 0.35`; нет копипасты целого § KB.

## Связь с realize v0

| realize v0 | explain concept |
|------------|-----------------|
| `explain_rule`, `compare_forms` | `explain_concept` |
| 1–2 предложения | 3–6 предложений, структура урока |
| atoms из rule claim | slots из concept card |

Realize v0 **остаётся** для быстрых норм; при «что такое / почему» — переключение act, не расширение тех же шаблонов.
