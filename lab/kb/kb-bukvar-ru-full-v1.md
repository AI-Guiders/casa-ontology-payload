# kb-bukvar-ru-full-v1

Полный кириллический алфавит (B0) + **все открытые слоги** V+CV (B1) + primer B2.

- B1 open: 10 гласных + 21×10 = **220** слогов (ма, па, …, щя)
- B1 special: ъ/ь (объ, ль, …) + CVC primer (мам, пап)
- Итого ~232 слога — **конечный** набор для букваря открытых слогов

Генерация: `python tools/gen_kb_bukvar_ru_full.py`

Закрытые CVC (сон, мир, …) — отдельный расширенный корпус; их ~тысячи, не влезают в одну 32×32 решётку с копиями.
