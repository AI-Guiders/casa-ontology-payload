# Cursive / propisi fonts for grapheme PNG export

Lab tool: `python tools/grapheme_glyph_export.py`

## Preferred: ScriptS (latn + cyrl)

Place **`ScriptS.ttf`** here (from ofont.ru / user download).  
Covers **26** Latin + **33** Cyrillic cursive glyphs in one font.

## Fallback Latin (Windows)

**Script MT Bold** — `%WINDIR%\Fonts\SCRIPTBL.TTF` — if ScriptS not present.

## Fallback Cyrillic

**Propisi** (`Propisi.ttf`) — if ScriptS not present.
